# ML_Tasks

This is a repository containing various ML tasks, mostly from various courses taken at ETH.

## Current Structure

- `IML_FS24/`: Tasks from ETH's "Introduction to Machine Learning" Course in FS 2024.
- `HoDL_HS24/`: Tasks from ETH's "Hands-On Deep Learning" Course in HS 2024.


### Tasks in `IML_FS24`
These use python, numpy, pandas, scikit-learn, matplotlib, seaborn python libraries. In the last 2 tasks pytorch is used and in the last transformers is used as well.

- [`task1a`](https://github.com/ElenaDesiato/ML_Tasks/tree/main/IML_FS24/task1a) , [`task1b`](https://github.com/ElenaDesiato/ML_Tasks/tree/main/IML_FS24/task1b)  
  Task 1 involves ridge regression & cross-validation.

- [`task2`](https://github.com/ElenaDesiato/ML_Tasks/tree/main/IML_FS24/task2)  
  Task 2 involves some light cleaning up of data, involving handling missing or non-numerical data. Afterwards Gaussian process     regression with differing kernels is used.

- [`task3`](https://github.com/ElenaDesiato/ML_Tasks/tree/main/IML_FS24/task3)  
  Task 3 involves using a pre-trained model from pytorch without its last layer to extract embeddings from images. Then create training data using triplets of image embeddings and use a custom neural net to binary classify the triplets.

- [`task4`](https://github.com/ElenaDesiato/ML_Tasks/tree/main/IML_FS24/task4)  
  Task 4 involves creating a custom dataset & dataloader, using a pre-trained model from transformers to get text embeddings before using a custom neural network to process embeddings and make predictions on a 0-10 scale.

### Tasks in `HoDL_HS24`
These are mainly notebooks with detailed descriptions & some exercises that I filled out. Topics include: Training Neural Nets, Audio Processing, Generative Computer Vision (Representation Learning, VAEs) , Graph Neural Networks, Natural Language Processing (RNNs, Finetuning,...) & Reinforcement Learning (Q-Learning, DQNs, ...).
